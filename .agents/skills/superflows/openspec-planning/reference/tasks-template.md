# Tasks Template

## 文件位置
`openspec/changes/<change-id>/tasks.md`

## 基本结构

```markdown
## 1. 实现阶段名称
- [ ] 1.1 具体任务
- [ ] 1.2 具体任务

## 2. 测试阶段
- [ ] 2.1 单元测试
- [ ] 2.2 集成测试

## 3. 文档阶段
- [ ] 3.1 更新文档
```

## 示例

```markdown
## 1. 数据库和模型
- [ ] 1.1 创建 approval 表迁移脚本
- [ ] 1.2 创建 Approval 模型和类型定义
- [ ] 1.3 添加资源申请表的 approval_status 字段

## 2. 审批服务
- [ ] 2.1 实现审批工作流引擎集成
- [ ] 2.2 创建审批 API 端点（创建、查询、批准、拒绝）
- [ ] 2.3 修改资源申请服务，插入审批步骤

## 3. 前端界面
- [ ] 3.1 创建审批列表页面
- [ ] 3.2 创建审批详情和操作组件
- [ ] 3.3 更新资源申请页面，显示审批状态

## 4. 测试
- [ ] 4.1 审批服务单元测试
- [ ] 4.2 审批流程集成测试
- [ ] 4.3 前端组件测试

## 5. 文档
- [ ] 5.1 更新 API 文档
- [ ] 5.2 更新用户手册
```

## 关键要点

1. **分阶段**：按逻辑模块或依赖关系分组
2. **可追踪**：每个任务都有明确的完成标准
3. **粒度适中**：不要太粗（"实现功能"）也不要太细（"添加一行代码"）
4. **包含测试**：确保有测试阶段
5. **包含文档**：确保有文档更新任务
