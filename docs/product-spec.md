# Claw Box 产品规格说明

## 产品概述

Claw Box 是个人 AI 助手的桌面控制台，提供会话管理、Agent Teams 协作、记忆系统、技能与 MCP 管理的统一界面。采用前后端分离架构，前端为桌面应用（Tauri/Electron），后端为 Core Service（Rust）。

## 核心功能模块

### 1. 会话管理

**功能描述**
- 支持创建、删除、重命名会话
- 会话列表展示，包含会话名称、状态、模型、Token 使用
- 会话搜索和过滤
- 运行态（Run/Step）实时展示

**数据结构**
- 会话 ID（唯一标识）
- 会话名称
- 创建时间
- 最后更新时间
- 关联的模型
- 消息历史
- 会话状态（运行中/空闲/等待/暂停）

### 2. Agent Teams 管理

**功能描述**
- 团队创建与角色配置
- 协作流程编排（顺序/并行/专家/流水线）
- 运行态可视化（Run/Step）
- 任务分配与结果聚合

**团队模式**
- 顺序模式（Sequential）
- 并行协作模式（Parallel）
- 专家咨询模式（Expert）
- 流水线模式（Pipeline）

### 3. 记忆系统

**功能描述**
- 长期记忆存储与管理
- 向量检索与语义匹配
- 记忆标签化与分类
- 记忆编辑与删除

**记忆类型**
- 长期记忆（持久化存储）
- 短期记忆（会话上下文）
- 向量 embedding（语义检索）

### 4. 技能管理

**功能描述**
- 技能安装和卸载
- 技能配置管理
- 技能执行监控
- 权限控制

**技能分类**
- 数据处理
- 文件操作
- 网络请求
- 系统集成
- MCP 工具映射

### 5. MCP 集成

**功能描述**
- MCP 服务器连接管理
- 工具和资源发现
- 实时调用监控
- 调用日志记录

**支持的 MCP 功能**
- 文件系统访问
- 数据库操作
- API 调用
- 浏览器自动化
- 自定义协议

## 用户界面布局

### 主界面结构

```
┌─────────────────────────────────────────────────────┐
│  [Logo] Claw Box        [模型选择器]    [设置] [用户] │
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  会话列表  │           主工作区                        │
│          │                                          │
│  [+新建]  │     [会话内容/对话界面]                    │
│          │                                          │
│  会话1    │                                          │
│  会话2    │                                          │
│  会话3    │     [运行态展示]                          │
│  ...     │     - Run/Step 状态                       │
│          │     - Token 使用                          │
│          │     - 响应时间                            │
│          │                                          │
├──────────┴──────────────────────────────────────────┤
│  [Teams] [记忆] [技能] [MCP]                         │
└─────────────────────────────────────────────────────┘
```

### 界面组件

1. **顶部导航栏**
   - 应用标识
   - 模型切换下拉菜单
   - 设置按钮
   - 用户信息

2. **左侧会话列表**
   - 新建会话按钮
   - 会话搜索框
   - 会话列表（可滚动）
   - 会话操作菜单（右键）

3. **主工作区**
   - 会话对话界面
   - 消息输入框
   - 运行态展示（Run/Step）
   - 上下文信息展示

4. **底部功能栏**
   - Agent Teams 入口
   - 记忆管理入口
   - 技能管理入口
   - MCP 管理入口

## 技术要求

### 前端技术栈
- Tauri（优先）或 Electron（桌面应用框架）
- React 18+（UI 框架）
- TypeScript（类型安全）
- Vite（构建工具）
- TailwindCSS（样式）
- Zustand（状态管理）

### 后端技术栈
- Rust（Core Service）
- Axum/Actix-web（HTTP 框架）
- SQLite（默认数据库）
- 本地向量检索（记忆系统）

### 数据存储
- SQLite（会话、记忆、配置）
- 本地向量索引（embedding）
- 可选：PostgreSQL + Qdrant/pgvector + Redis

### 性能要求
- 应用启动时间 < 3 秒
- 会话切换响应 < 200ms
- 消息渲染流畅（60fps）
- 内存占用 < 500MB（前端）

## 部署方式

- 单机一体化部署（单二进制 + 内嵌前端）
- 默认零中间件依赖
- 可选外部数据库与向量库
