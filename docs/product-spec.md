# Claw Box 产品规格说明

## 产品概述

Claw Box 是一个基于 Electron 的桌面应用，为 AI 助手提供统一的管理界面。支持多会话管理、模型切换、任务调度、技能扩展和团队协作等核心功能。

## 核心功能模块

### 1. 多会话管理

**功能描述**
- 支持创建、删除、重命名会话
- 会话列表展示，包含会话名称、最后活动时间、消息数量
- 会话搜索和过滤
- 会话归档和恢复
- 会话导出和导入

**数据结构**
- 会话 ID（唯一标识）
- 会话名称
- 创建时间
- 最后更新时间
- 关联的模型
- 消息历史
- 会话状态（活跃/归档）

### 2. 模型切换

**功能描述**
- 支持多个 AI 模型提供商（Claude、GPT、本地模型等）
- 实时切换当前会话使用的模型
- 显示模型状态（可用/不可用）
- 模型配置管理（API Key、端点等）
- 模型性能指标展示

**支持的模型**
- Claude 系列（Opus、Sonnet、Haiku）
- GPT 系列
- 本地部署模型
- 自定义模型接入

### 3. 会话状态管理

**功能描述**
- 实时显示会话运行状态
- 消息发送/接收状态
- Token 使用统计
- 响应时间监控
- 错误状态提示

**状态类型**
- 空闲（Idle）
- 处理中（Processing）
- 等待响应（Waiting）
- 错误（Error）
- 已完成（Completed）

### 4. 定时任务管理

**功能描述**
- 创建定时执行的任务
- 支持 Cron 表达式
- 任务执行历史记录
- 任务状态监控
- 任务结果通知

**任务类型**
- 定时查询
- 数据同步
- 报告生成
- 自动化脚本

### 5. 技能系统

**功能描述**
- 技能安装和卸载
- 技能配置管理
- 技能执行监控
- 技能版本管理
- 技能依赖处理

**技能分类**
- 数据处理
- 文件操作
- 网络请求
- 系统集成
- 自定义扩展

### 6. MCP（Model Context Protocol）集成

**功能描述**
- MCP 服务器连接管理
- 工具和资源发现
- 实时调用监控
- 权限管理
- 配置同步

**支持的 MCP 功能**
- 文件系统访问
- 数据库操作
- API 调用
- 浏览器自动化
- 自定义协议

### 7. Agent Teams 状态管理

**功能描述**
- 多 Agent 协作管理
- Agent 角色分配
- 任务分发和协调
- 团队状态可视化
- 协作历史记录

**团队模式**
- 主从模式（Leader-Follower）
- 平行协作模式
- 专家咨询模式
- 流水线模式

### 8. 项目管理

**功能描述**
- 项目创建和配置
- 项目文件关联
- 项目上下文管理
- 项目模板
- 项目导出和分享

**项目属性**
- 项目名称和描述
- 关联的会话
- 项目文件路径
- 项目配置
- 项目成员（多用户场景）

### 9. 技能市场管理

**功能描述**
- 浏览可用技能
- 技能搜索和过滤
- 技能评分和评论
- 技能安装和更新
- 本地技能发布

**市场功能**
- 热门技能推荐
- 分类浏览
- 版本历史
- 依赖检查
- 安全审核

## 用户界面布局

### 主界面结构

```
┌─────────────────────────────────────────────────────┐
│  [Logo] Claw Box        [模型选择器]    [设置] [用户] │
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  会话列表  │           主工作区                        │
│          │                                          │
│  [+新建]  │     [会话内容/对话界面]                    │
│          │                                          │
│  会话1    │                                          │
│  会话2    │                                          │
│  会话3    │     [会话状态卡片]                         │
│  ...     │     - Token 使用                          │
│          │     - 响应时间                            │
│          │     - 模型状态                            │
│          │                                          │
├──────────┴──────────────────────────────────────────┤
│  [任务] [技能] [Teams] [项目] [市场]                  │
└─────────────────────────────────────────────────────┘
```

### 界面组件

1. **顶部导航栏**
   - 应用标识
   - 模型切换下拉菜单
   - 设置按钮
   - 用户信息

2. **左侧会话列表**
   - 新建会话按钮
   - 会话搜索框
   - 会话列表（可滚动）
   - 会话操作菜单（右键）

3. **主工作区**
   - 会话对话界面
   - 消息输入框
   - 会话状态卡片
   - 上下文信息展示

4. **底部功能栏**
   - 定时任务入口
   - 技能管理入口
   - Agent Teams 入口
   - 项目管理入口
   - 技能市场入口

## 技术要求

### 前端技术栈
- Electron（桌面应用框架）
- React 18+（UI 框架）
- TypeScript（类型安全）
- Vite（构建工具）
- TailwindCSS（样式）

### 数据存储
- 本地 JSON 文件（会话数据）
- IndexedDB（大量数据）
- LocalStorage（配置信息）

### 性能要求
- 应用启动时间 < 3 秒
- 会话切换响应 < 200ms
- 消息渲染流畅（60fps）
- 内存占用 < 500MB
