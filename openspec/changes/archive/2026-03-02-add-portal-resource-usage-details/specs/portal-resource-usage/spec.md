## ADDED Requirements
### Requirement: 门户资源使用概览详情入口
系统 MUST 支持普通用户从工作台资源使用概览卡片进入只读详情页。

#### Scenario: 点击卡片进入详情
- **WHEN** 用户点击工作台资源使用概览中的任一资源卡片
- **THEN** 系统展示对应资源类型的只读详情页

### Requirement: 资源详情页只读概览布局
系统 MUST 为算力、模型、知识库、智能体提供一致的只读概览布局。

#### Scenario: 统一布局展示
- **WHEN** 用户进入任一资源详情页
- **THEN** 页面包含 KPI 概览、趋势区块、告警或活动列表

### Requirement: 资源类型差异化指标
系统 MUST 根据资源类型展示差异化指标集合。

#### Scenario: 算力与模型指标区分
- **WHEN** 用户查看算力或模型详情页
- **THEN** 页面展示符合该资源类型的关键指标
