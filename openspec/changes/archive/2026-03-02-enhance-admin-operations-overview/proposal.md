# Change: 增强 B 端运营服务概览页面

## Why

当前 B 端运营服务概览页面展示形式过于简单，仅有基础的概览卡片，无法满足一级管理员（大数据中心）和运营团队的全局管理需求。需要丰富运营概览内容，展示全局资源情况、部门统计分析数据，并针对模型、智能体、知识库、算力四大资源类型设计细化的概览页面，提升数据可视化能力。

## What Changes

- 重构 B 端运营服务概览首页，采用"运营驾驶舱"布局，包含全局 KPI、资源水位、部门对比、趋势分析、审批进度、告警列表六大模块
- 新增四大资源类型（模型、智能体、知识库、通用算力）的细化概览页面，支持从首页资源水位卡片跳转
- 新增部门对比与趋势分析功能，支持多维度筛选（时间、部门、资源类型、环境）
- 优化审批进度与告警列表展示，增加停留时长预警、告警级别标识等功能
- 通用算力仅在管理端展示，增加算力池分布、部门配额对比、超限预警等专属功能

## Impact

- Affected specs: 新增 `admin-operations-overview` capability
- Affected code: 
  - B 端运营服务概览页面组件（`src/pages/admin/operations-overview/`）
  - 资源详情页面组件（`src/pages/admin/resource-details/`）
  - 相关数据接口与 API 调用
