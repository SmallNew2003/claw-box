## ADDED Requirements
### Requirement: Mini Sidebar
The system SHALL display a compact left-side icon sidebar on the QA page with entries for "对话" and "知识库管理".

#### Scenario: Sidebar visible
- **WHEN** a user views the QA page
- **THEN** the mini sidebar shows icon entries for "对话" and "知识库管理"

### Requirement: Hover Tooltip
The system SHALL show a small text tooltip when the user hovers over a mini sidebar icon.

#### Scenario: Hover icon
- **WHEN** a user hovers over an icon
- **THEN** a small text tooltip displays the entry name
