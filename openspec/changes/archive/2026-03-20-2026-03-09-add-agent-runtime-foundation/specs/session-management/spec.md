## MODIFIED Requirements

### Requirement: 会话上下文状态
系统 SHALL 显示会话的模型、运行状态、最近执行结果与上下文占用信息。

#### Scenario: 查看会话状态
- **WHEN** 用户选中某个会话
- **THEN** 系统显示该会话的模型名称、运行状态、最近一次执行结果与上下文占用
- **AND** 在执行中展示进行中的状态标识

#### Scenario: 上下文占用警告
- **WHEN** 会话上下文占用超过 80%
- **THEN** 系统显示警告提示用户清理历史消息

#### Scenario: 查看失败状态
- **WHEN** 会话最近一次执行失败
- **THEN** 系统显示失败状态和错误摘要
- **AND** 支持用户查看对应的运行日志
