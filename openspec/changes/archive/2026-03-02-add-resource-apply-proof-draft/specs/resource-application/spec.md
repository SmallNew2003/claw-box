## ADDED Requirements
### Requirement: 申请资源支持证明材料上传
系统 SHALL 在申请资源页面提供证明材料上传入口，并在提交前展示已选择文件列表。

#### Scenario: 选择证明材料
- **WHEN** 用户在申请资源页面选择本地文件
- **THEN** 系统在表单中展示文件信息并允许移除

### Requirement: 申请资源支持暂存草稿
系统 SHALL 允许用户在申请资源页面暂存当前表单内容，并在再次进入时提示恢复。

#### Scenario: 暂存草稿
- **WHEN** 用户点击“暂存”
- **THEN** 系统将当前表单内容保存为草稿

#### Scenario: 恢复草稿
- **WHEN** 用户进入申请资源页面且存在草稿
- **THEN** 系统提示用户是否恢复草稿内容
