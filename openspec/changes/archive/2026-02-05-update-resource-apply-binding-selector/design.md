# 设计说明：移除关联已有 + 智能体绑定抽屉选择

## 1. 模型/知识库申请
- 申请条目仅保留“新申请”字段，不再出现来源类型。
- 卡片展示去掉来源类型字段，保持全量信息展示。

## 2. 智能体绑定选择
- 智能体编辑抽屉内不再使用下拉。
- 绑定模型/知识库使用“选择”按钮打开右侧抽屉。
- 抽屉内以卡片形式展示可选资源，支持多选勾选并确认。
- 列表包含两类资源：
  - 本次申请资源（来自模型/知识库申请列表）
  - 已有资源（来自当前用户可见资源列表）
- 卡片上用标签区分“本次申请/已有资源”。

## 3. 卡片操作
- 卡片头部新增“编辑”按钮（点击打开编辑抽屉）。
- 删除按钮保留在卡片右上角。

## 4. 绑定数据表示
- 智能体绑定值使用统一数组，值采用前缀区分来源：
  - `req:<requestId>` 表示本次申请资源
  - `existing:<resourceId>` 表示已有资源
- 展示与回显时通过前缀解析并映射名称。
