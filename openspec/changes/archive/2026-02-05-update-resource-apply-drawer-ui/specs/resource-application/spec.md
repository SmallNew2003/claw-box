## ADDED Requirements

### Requirement: 资源申请列表改为卡片展示 + 抽屉编辑
系统 SHALL 在模型/知识库/智能体申请 Tabs 中展示卡片列表，新增/编辑统一使用右侧抽屉，抽屉一次仅编辑一个条目。

#### Scenario: 用户点击卡片
- **WHEN** 用户点击某条申请卡片
- **THEN** 系统在右侧抽屉打开该条目的编辑表单

### Requirement: 卡片展示尽量完整信息
系统 SHALL 在卡片中尽量展示条目全量信息，长文本字段默认两行省略并支持展开查看。

#### Scenario: 展开长文本
- **WHEN** 用户点击“展开”
- **THEN** 系统显示完整文本内容并允许收起

### Requirement: 空状态与新增按钮规则
系统 SHALL 在空状态显示大按钮引导新增，非空状态在 Tab 顶部显示新增按钮。

#### Scenario: 空状态
- **WHEN** 某 Tab 无条目
- **THEN** 系统显示大按钮用于创建条目

### Requirement: 删除入口在卡片右上角
系统 SHALL 在每张卡片右上角提供删除入口。

#### Scenario: 删除条目
- **WHEN** 用户点击卡片右上角删除
- **THEN** 系统删除该条目并同步更新绑定关系
