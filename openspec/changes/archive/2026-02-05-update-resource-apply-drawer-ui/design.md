# 设计说明：卡片列表 + 右侧抽屉编辑

## 1. 页面结构
- 基本信息固定区域保持不变。
- Tabs 保持：模型申请 / 知识库申请 / 智能体配置。
- Tab 内仅显示卡片列表（全量信息展示）与新增按钮。

## 2. 新增/编辑交互
- 点击“新增”打开右侧抽屉，表单内容与当前条目结构一致。
- 点击卡片打开抽屉进行编辑。
- 抽屉一次只编辑一个条目，保存后更新卡片。

## 3. 卡片展示
- 卡片尽量展示全部字段，分组展示（基础/配置/备注）。
- 长文本字段（业务描述、功能需求、数据来源等）默认两行省略，可点击“展开/收起”。
- 删除按钮放在卡片右上角。

## 4. 空状态与新增按钮
- 空状态显示大按钮（如“新增模型申请”）。
- 非空状态 Tab 顶部显示“新增”按钮。

## 5. 约束
- 不改变数据结构与提交流程，仅调整 UI 与交互。
