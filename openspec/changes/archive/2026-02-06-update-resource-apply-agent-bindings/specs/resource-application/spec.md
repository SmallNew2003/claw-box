## ADDED Requirements

### Requirement: 智能体绑定使用弹窗 Tabs 多选
系统 SHALL 在智能体配置中使用弹窗 Tabs 进行模型/知识库/插件/MCP 多选绑定，替代抽屉选择。

#### Scenario: 点击选择模型
- **WHEN** 用户点击“选择模型”
- **THEN** 系统打开绑定弹窗并默认展示模型 Tab，允许多选

### Requirement: 绑定弹窗展示来源标签
系统 SHALL 在绑定弹窗中同时展示“本次申请”与“已有资源”的来源标签。

#### Scenario: 打开绑定弹窗
- **WHEN** 用户打开绑定弹窗
- **THEN** 系统为每个条目展示来源标签

### Requirement: 智能体支持绑定插件与 MCP
系统 SHALL 支持智能体绑定插件与 MCP 资源，选择规则与模型/知识库一致。

#### Scenario: 选择插件或 MCP
- **WHEN** 用户在插件或 MCP Tab 中勾选条目并确认
- **THEN** 系统保存绑定并在智能体表单中回显

### Requirement: 绑定资源卡片展示关键指标标签
系统 SHALL 在绑定弹窗的资源卡片中展示关键指标标签，用于辅助选择与辨识。

#### Scenario: 模型与知识库卡片展示
- **WHEN** 用户查看模型或知识库卡片
- **THEN** 系统展示申请模式/QPS/TPM或知识库类型/向量库/容量等关键标签（缺失则不展示）

#### Scenario: 插件与 MCP 卡片展示
- **WHEN** 用户查看插件或 MCP 卡片
- **THEN** 系统展示资源编号标签

### Requirement: 绑定弹窗支持搜索、宫格布局与分页
系统 SHALL 在绑定弹窗中支持资源搜索、宫格卡片布局与前端分页。

#### Scenario: 搜索资源
- **WHEN** 用户输入搜索关键词
- **THEN** 系统按标题与描述进行模糊匹配并刷新结果

#### Scenario: 宫格卡片布局
- **WHEN** 用户查看绑定弹窗
- **THEN** 系统以多列宫格方式展示卡片

#### Scenario: 前端分页
- **WHEN** 用户在结果超过单页数量时翻页
- **THEN** 系统在前端切换分页结果，默认每页 9 条

### Requirement: 绑定资源卡片为媒体卡片
系统 SHALL 在绑定弹窗中使用媒体卡片样式展示资源信息。

#### Scenario: 媒体卡片内容
- **WHEN** 用户查看绑定弹窗卡片
- **THEN** 卡片展示封面、标题、来源、描述与指标标签
